# 📊 Atividade de Paradigmas de Linguagens de Programação

Este repositório contém a implementação de um algoritmo desenvolvido em **Python** e **C** com o objetivo de comparar a sintaxe, a tipagem e o comportamento estrutural de uma linguagem interpretada dinamicamente versus uma linguagem compilada estaticamente.

## 📝 Descrição da Tarefa
O algoritmo tem como objetivo:
1. Ler $N$ números inteiros informados pelo usuário.
2. Calcular a **soma** total dos números.
3. Contar a quantidade de números **pares**.
4. Calcular a **média** aritmética utilizando uma **função auxiliar** declarada antes do bloco principal.
